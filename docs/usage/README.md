# راهنمای استفاده — به زبان ساده

این پوشه، دستورالعمل استفادهٔ **همهٔ** بخش‌های سامانه است؛ آن‌قدر ساده که هر کسی
—حتی اگر تا حالا با پنل کار نکرده— بتواند دنبال کند. هر بخش سه چیز را می‌گوید:

- **این چیست؟** — یک جملهٔ ساده.
- **ادمین چه می‌کند؟** — قدم‌به‌قدم، دکمه‌به‌دکمه.
- **کاربر/مشتری چه می‌بیند؟** — اگر برای مشتری هم چیزی دارد.

## دو پنل جدا داریم — این‌ها را قاطی نکنید

1. **پنل نایت (KNIGHT)** — جای صاحبِ *سکو*. این‌جا فروشگاه‌ها ساخته و مدیریت
   می‌شوند، فیچرها منتشر و روی فروشگاه‌ها نصب می‌شوند، پلن و صورتحساب و سلامت
   سرورها این‌جاست. آدرس: `knight.abolfazltafakori.com`.
   👈 راهنما: [`knight-control-plane.md`](knight-control-plane.md)

2. **پنل فروشگاه (بوژان)** — جای صاحب و کارکنانِ *فروشگاه*. این‌جا محصول و سفارش و
   مشتری و تخفیف و گزارش‌ها را می‌بینید، و فیچرهای نصب‌شده در منوی «افزونه‌ها»
   ظاهر می‌شوند. آدرس مدیریت: `admin.bojanstore.com`، ویترین: `bojanstore.com`.
   👈 راهنما: [`store-panel.md`](store-panel.md)

3. **فیچرها (افزونه‌ها)** — قابلیت‌هایی که صاحب فروشگاه می‌خرد/نصب می‌کند و بعد در
   «افزونه‌ها»ی پنل فروشگاه از آن‌ها استفاده می‌کند (جستجوی پیشرفته، انبار، تخفیف،
   اشتراک، …).
   👈 راهنما: [`features.md`](features.md)

4. **پورتال خودخدمت** — جایی که صاحب فروشگاه ثبت‌نام می‌کند، پلن می‌خرد و فیچرها را
   فعال می‌کند. بخشی از پنل نایت است و در همان راهنمای نایت توضیح داده شده.

## یک قانون طلایی
هر دکمه‌ای که «ثبت»، «ارسال»، «حذف» یا «تأیید» است، **کارِ واقعی انجام می‌دهد**.
قبل از زدنش یک‌بار نوشته‌ها را بخوانید. کارهای برگشت‌ناپذیر (مثل حذف) را جداگانه
هشدار داده‌ایم.
